# VAKS Global Trading Co.

A static business website for VAKS Global Trading Co. (VGTC), a B2B importer and exporter of fresh fruits and vegetables from Pakistan serving markets across the UAE, Qatar, Oman, Asia, and Europe.

## Overview

This project is a multi-page marketing website built with plain HTML, Tailwind CSS via CDN, and JavaScript. It presents the company’s services, products, markets, and contact information in a polished, responsive layout.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS CDN
- Font Awesome
- AOS (Animate On Scroll)

## Features

- Responsive landing page for a fresh produce export company
- Sticky navigation and mobile menu
- Product and services showcase pages
- Market coverage and company information pages
- FAQ accordion interaction
- Animated counters and scroll effects
- Quote inquiry modal with WhatsApp integration
- Direct contact links for UAE and Pakistan phone numbers

## Pages

- `index.html` — Home page
- `about.html` — About the company
- `services.html` — Services offered
- `products.html` — Product catalog
- `markets.html` — Export markets
- `contact.html` — Contact details
- `faqs.html` — Frequently asked questions

## How to Run

Because this is a static site, you can run it in any of the following ways:

### Option 1: Open directly in browser

Open `index.html` in a browser.

### Option 2: Use a local static server

```bash
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```

## Notes

- The site uses Tailwind via CDN, so there is no package installation required.
- Images and assets are stored in the root folder and `realImages/`.
- The JavaScript file `script.js` handles menu behavior, FAQ interactions, modal logic, animation setup, and WhatsApp quoting flows.

## Purpose

This repository is a business website targeting B2B buyers and importers looking for fresh fruit and vegetable sourcing from Pakistan.
